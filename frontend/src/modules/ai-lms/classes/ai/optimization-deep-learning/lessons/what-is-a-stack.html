What is a Stack?

A stack is a linear collection with one strict rule: Last In, First Out (LIFO). New items go on top, and only the top item can be removed. That single constraint is what makes stacks so fast, so predictable, and so ubiquitous — from your browser's back button to the call stack inside every running program.

01 The Core Idea

Think of a stack of plates at a cafeteria. You can't pull the bottom plate without lifting every plate above it. You add a plate to the top, and you remove a plate from the top. Nothing else is allowed.

Two operations, one rule

push(x) Add x to the top.
pop() Remove and return the top element.
peek() Look at the top without removing it.
isEmpty() Check whether the stack has any elements.

LIFO invariant: the element you pushed most recently is always the first one you can pop. This is the entire contract — everything else is implementation detail.

Why "Last In, First Out" matters

LIFO naturally models nesting and reversal: matching brackets, undoing edits, backtracking through a maze, or resolving function calls that call other functions. Whenever a problem says "go back to where you were," a stack is probably the right tool.

02 Implementing a Stack

A stack is an abstract data type — it defines behavior, not storage. You can build it on top of an array or a linked list. Here is a minimal array-backed stack in JavaScript:

// A stack backed by a plain array. All operations are O(1).
class Stack {
  constructor() {
    this.items = [];
  }

  push(value) {
    this.items.push(value);   // add to the top
    return this;
  }

  pop() {
    if (this.isEmpty()) throw new Error("Stack underflow");
    return this.items.pop();  // remove from the top
  }

  peek() {
    return this.items[this.items.length - 1];
  }

  isEmpty() {
    return this.items.length === 0;
  }

  size() {
    return this.items.length;
  }
}

// Usage
const s = new Stack();
s.push("A").push("B").push("C");
console.log(s.peek());  // "C"
console.log(s.pop());   // "C"
console.log(s.pop());   // "B"

Complexity at a glance

OperationTimeNotes
pushO(1)Amortized O(1) for a dynamic array; worst case O(n) on resize.
popO(1)Just remove the last element.
peekO(1)Read the top index.
search(x)O(n)Not part of the stack contract — you'd have to scan.
Underflow vs. overflow. Popping an empty stack is underflow; pushing onto a fixed-capacity stack that's full is overflow. Real code should decide whether to throw, return a sentinel, or grow dynamically.

03 Where Stacks Show Up

Classic applications

  • Function call stack — every language runtime uses one to track active calls and return addresses.
  • Undo/redo — each edit is pushed; undo pops it.
  • Balanced brackets — push openers, pop on closers.
  • Expression evaluation — reverse Polish notation, infix-to-postfix conversion.
  • DFS / backtracking — explore deeper, then unwind.
  • Browser history — the back button is a pop.

Balanced brackets, in 12 lines

function isBalanced(str) {
  const pairs = { ")":"(", "]":"[", "}":"{" };
  const stack = [];
  for (const ch of str) {
    if ("([{".includes(ch)) {
      stack.push(ch);        // remember an opener
    } else if (pairs[ch]) {
      if (stack.pop() !== pairs[ch]) return false;
    }
  }
  return stack.length === 0;   // nothing left unclosed
}
