The Stack

A tiny structure with enormous power. Master the Last-In, First-Out principle that powers function calls, undo buttons, and expression parsers everywhere.

1 What Is a Stack?

A stack is a linear data structure where elements are added and removed from only one end — called the top.

🍽️ A Stack of Plates

You add a clean plate on top. You take the top plate off. You never pull from the middle — that's the whole point.

↩️ The Undo Button

Each action is pushed onto a stack. Pressing Undo pops the most recent action first. Last action in → first action undone.

LIFO: Last In, First Out. The element you pushed most recently is the one you pop next.

2 Core Operations

A stack exposes a tiny, focused API. That's its strength.

O(1) push(x)

Add element x to the top.

O(1) pop()

Remove and return the top element.

O(1) peek()

Look at the top without removing it.

O(1) isEmpty()

Check whether the stack holds any elements.

Why O(1)? Every operation touches only the top. There's no scanning, no shifting, no searching — just a pointer update.

4 A Minimal Implementation

Under the hood, a stack is just an array with a restricted interface.

class Stack {
  constructor() {
    this.items = [];   // the underlying storage
  }

  push(value) {
    this.items.push(value);
    return value;
  }

  pop() {
    if (this.isEmpty()) return null;
    return this.items.pop();
  }

  peek() {
    return this.items[this.items.length - 1] ?? null;
  }

  isEmpty() {
    return this.items.length === 0;
  }

  size() {
    return this.items.length;
  }
}

// Usage
const s = new Stack();
s.push("a");
s.push("b");
s.push("c");
console.log(s.pop());   // "c"  ← last in, first out
console.log(s.peek());  // "b"

5 Where Stacks Show Up

Function Call Stack

Every function call pushes a frame. When it returns, the frame is popped. That's how your program remembers where to go back to.

Undo / Redo

Editors keep a stack of actions. Undo pops the last action; redo pushes it onto a second stack.

Balanced Brackets

Push opening brackets, pop on closing ones. If the stack is empty at the end — the expression is balanced.

Expression Evaluation

Postfix (RPN) calculators use a stack to evaluate 3 4 + 5 * without any parentheses.
