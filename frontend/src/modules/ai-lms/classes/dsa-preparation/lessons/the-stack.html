01 The Mental Model

Forget code for a second. Picture a stack of plates in a cafeteria. You add a clean plate to the top. When you need one, you take from the top. The plate that has been sitting at the bottom the longest is the last to leave.

The LIFO Invariant

A stack is a restricted linear data structure. Unlike an array where you can touch any index, a stack exposes exactly one end — the top. Every operation flows through it.

push(x)

Place x on top. It becomes the new top.

pop()

Remove and return the top element. The one below is now exposed.

peek() / top()

Read the top element without removing it.

isEmpty()

True when no elements remain. Guard your pops with this.

Key Insight The stack's power comes from its constraint. By forbidding random access, it forces a discipline that mirrors real problems: nested structures, reversal, and backtracking. When a problem says "the most recent thing matters most," reach for a stack.

03 Complexity Derivation

Why is every core operation O(1)? Let's derive it, not just assert it.

In an array-backed stack, we maintain a single index variable top. 

# Array-backed stack with a top index
stack = []          # backing array

def push(x):
    stack.append(x)  # write at index len(stack); top = len-1

def pop():
    return stack.pop()  # read + remove at index len-1

Both push and pop touch a constant number of memory cells at a known index. No element is shifted, no loop runs. The work is independent of n — the current number of elements. Hence O(1) time.

Space is O(n): we store exactly one slot per element. The top pointer itself is a single word — O(1) auxiliary space.

Amortized Note Python's list.append occasionally resizes the backing array (doubling capacity). That single push costs O(n), but spread across n pushes it averages to O(1) amortized. Interviewers love this nuance.

04 Idiomatic Implementations

In production you'd use the language's built-in. But interviewers often ask you to build one from scratch — know both. 

class Stack:
    def __init__(self):
        self._data = []

    def push(self, x) -> None:
        self._data.append(x)          # O(1) amortized

    def pop(self):
        if not self._data:            # guard: never pop empty
            raise IndexError("pop from empty stack")
        return self._data.pop()        # O(1)

    def peek(self):
        if not self._data:
            raise IndexError("peek from empty stack")
        return self._data[-1]           # O(1)

    def is_empty(self) -> bool:
        return not self._data

    def __len__(self) -> int:
        return len(self._data)
class Stack<T> {
  private data: T[] = [];

  push(x: T): void {
    this.data.push(x);            // O(1) amortized
  }

  pop(): T {
    if (this.data.length === 0) {
      throw new Error("pop from empty stack");
    }
    return this.data.pop()!;      // O(1)
  }

  peek(): T {
    if (this.data.length === 0) {
      throw new Error("peek from empty stack");
    }
    return this.data[this.data.length - 1];
  }

  isEmpty(): boolean {
    return this.data.length === 0;
  }

  get size(): number {
    return this.data.length;
  }
}

05 Where Stacks Shine

Recognize these patterns on sight — they're the tell that a stack is the right tool.

🔁 Reversal & Undo

Undo/redo in editors, browser back button, reversing a string. The most recent action is always the first to be undone — a textbook LIFO fit.

🧮 Expression Evaluation

Infix → postfix conversion, evaluating "3 4 + 2 *". Operators apply to the two most recently seen operands.

🌳 DFS & Backtracking

Iterative depth-first search, maze solving, N-Queens. The call stack is a stack — recursion is just the language managing it for you.

🧩 Matching & Nesting

Balanced parentheses, HTML tag validation, JSON parsing. Each opener waits for its closer — the last opened must close first.

📈 Monotonic Stack

"Next greater element," largest rectangle in histogram, daily temperatures. A stack kept sorted reveals the nearest larger/smaller neighbor in O(n).

⏱️ Function Call Stack

Every program's runtime uses one. Each call pushes a frame; returning pops it. Stack overflow = you pushed too deep.

Edge Case Alert Always guard against popping an empty stack. In interviews, this is the #1 bug. Also watch for: single-element stacks, popping to exactly empty, and mismatched bracket types in matching problems.

07 Practice Problems

Work these in order. Each one trains a distinct stack muscle.

Valid Parentheses Medium

Push every opener. On a closer, the top must match. End with an empty stack. O(n) time, O(n) space. The canonical stack warm-up.

Min Stack Medium

Design a stack with O(1) push, pop, top, and getMin. The trick: a parallel stack where each entry stores the minimum so far. Quiz Q2 above is this problem.

Daily Temperatures Medium

For each day, find how many days until a warmer temperature. A monotonic decreasing stack of indices solves it in O(n) — the classic "next greater element" pattern.

Largest Rectangle in Histogram Hard

The boss level. A monotonic increasing stack of bar indices lets you compute each bar's maximal rectangle in O(n). Master this and monotonic stacks are yours forever.

Pattern Recognition When you see "nearest greater/smaller," "matching pairs," or "undo the most recent," your hand should reach for a stack before you finish reading the problem.
