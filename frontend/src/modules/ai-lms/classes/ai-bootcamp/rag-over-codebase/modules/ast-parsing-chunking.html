Why Naive Line Chunking Fails for Code

Chunking code by fixed character counts (e.g. 500 characters) cuts functions in half and destroys variable scope. Using Tree-Sitter AST guarantees every chunk represents an intact semantic unit (a full function, class, or method declaration).
