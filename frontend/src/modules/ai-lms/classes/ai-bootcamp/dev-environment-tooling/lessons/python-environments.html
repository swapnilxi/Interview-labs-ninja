Dependency Isolation: The Golden Rule

Installing packages into your system Python will inevitably break system utilities or create conflicting C-extension dependencies (such as mismatched numpy versions required by PyTorch and SciPy). Every project must have its own isolated environment.

Reproducible Project Workflow with pyproject.toml

Initialize a project directory with uv init. It creates a modern pyproject.toml and manages an exact lockfile:

# Initialize new AI project
uv init ai-agent-core
cd ai-agent-core

# Add dependencies with exact constraints
uv add torch transformers pydantic httpx

# Sync environment to match lockfile exactly
uv sync
