The Problem: Why AI Tooling Breaks

Most AI tutorials skip environment setup, leading to version hell, mismatched CUDA runtimes, and broken virtualenvs. In production AI engineering, your tools shape your thinking. We build bottom-up across four decoupled layers.

Step 1: Lightning-Fast Python with uv

We use Astral's uv — written in Rust, it installs dependencies 10-100x faster than pip and manages Python versions natively without pyenv.

# Install uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install pinned Python 3.12
uv python install 3.12

# Create and activate virtual environment
uv venv .venv --python 3.12
source .venv/bin/activate

# Install core tensor & data stack
uv pip install numpy torch torchvision

Step 2: Hardware Acceleration Verification

Test tensor allocations and verify GPU hardware acceleration for both NVIDIA CUDA and Apple Silicon Metal (MPS):

import torch

print(f"PyTorch Version: {torch.__version__}")

if torch.cuda.is_available():
    device = torch.device("cuda")
    print(f"CUDA Device: {torch.cuda.get_device_name(0)}")
elif torch.backends.mps.is_available():
    device = torch.device("mps")
    print("Apple Silicon Metal (MPS) is active.")
else:
    device = torch.device("cpu")
    print("Running on CPU.")

# Allocate matrix on device and verify dot product
x = torch.randn(1000, 1000, device=device)
y = torch.matmul(x, x.T)
print(f"Matrix multiply completed successfully on {device}. Shape: {y.shape}")
